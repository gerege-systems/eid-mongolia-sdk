### Added — тамганы гэрчилгээ олгуулах: `requestCertificate` / `getCertificateRequest` / `waitForCertificate`

- **Юу:** `eid.seal.requestCertificate(orgEtsi)` — `POST /seal/certificate/{orgEtsi}` → 202 `SealCertificateRequest` (`requestId`, `status: "PENDING"`, `expiresAt`, `approvers`); `eid.seal.getCertificateRequest(orgEtsi, requestId)` — `GET /seal/certificate/{orgEtsi}/requests/{requestId}` (`PENDING` | `APPROVED` | `ISSUED` + `certificate` | `REJECTED` | `EXPIRED` | `FAILED` + `failure`); `eid.seal.waitForCertificate(orgEtsi, requestId, { timeoutMs = 15 мин, intervalMs = 3 с, signal })` — ISSUED болтол асууж `SealCertificate` буцаана, 429/503 Retry-After-ийг дагана. Typed алдаа: `SealApproverUnavailableError` (409 `SEAL_APPROVER_UNAVAILABLE`), `SealRequestNotFoundError` (404 `SEAL_REQUEST_NOT_FOUND`), `SealCertificateRequestError` (`outcome`: REJECTED / EXPIRED / FAILED / TIMEOUT). `getCertificate`-ийн тайлбар: одоогийн олгогдсон гэрчилгээг буцаана, шинээр олгохгүй.
- **Яагаад:** CA !483 (`6ae854ab`, 2026-11-09) тамганы гэрчилгээний олголтыг байгууллагын ADMIN-ий PIN2 батлалттай болгосон — `POST /seal/certificate/{orgEtsi}` нь 200 + cert-ийн оронд 202 + хүсэлт буцаана (ORG_ONBOARDING §4.3).
- **Хаана:** `src/seal.ts`, `src/errors.ts`, `src/http.ts`, `src/contract.ts` (`sealCertificateRequest`; төлөвийн зам discovery-д хараахан алга тул `RP_ROUTES_UNDISCOVERED`), `src/index.ts`; тест `test/seal.test.ts` (бичлэгт хариу: бүх төгсгөлийн төлөв, 409/404/403/429, Retry-After, timeout, abort); README §3i.
