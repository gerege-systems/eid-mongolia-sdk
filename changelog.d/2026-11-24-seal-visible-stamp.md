### Feat — харагдах байгууллагын тамганы дардас (APPEARANCE_SPEC.md §6, golden v12)

- **Юу:** `prepare`-д `appearance` өгч `signerCert` нь e-Seal гэрчилгээ (§6.1: CA биш, KeyUsage-д nonRepudiation байгаа ба digitalSignature үгүй, EKU extension үгүй) бол иргэний дардасны оронд **тамганы дардас** зурна: ижил widget / 11 объект / F1, F2 фонт / байршил, гэхдээ `/EIDVerify` BDC, QR, URL, үүргийн мөр үгүй; бичвэр x = 4 pt-ээс, мөрүүд — нэр (F2), «eID Mongolia-аар тамгалсан» / "Sealed with eID Mongolia", огноо. `docId` шаардахгүй, 45 pt-ийн доод өндөр үгүй. Бусад бүх гэрчилгээнд иргэний дардас байт-ижил (golden v3–v11 хэвээр). `validatePdf` (own-signer): e-Seal гэрчилгээний revision-д URL шалгалтыг алгасаж тамганы дардсыг mn/en-ээр дахин үүсгэж тулгана; гэрчилгээ ба дардас аль ч чиглэлд зөрвөл өмнөх гарын үсгүүд `modified_after_signing`. `sealPdf` үл харагдах хэвээр; шинэ нийтийн API нэмээгүй.
- **Яагаад:** Портал байгууллагын тамгыг `prepare`-ээр харагдах байдлаар тавина; өмнө нь TS validator зөвхөн иргэний дардсыг дахин үүсгэдэг тул тамганы дардастай PDF-ийн өмнөх гарын үсгүүд «modified» болдог байв. Go SDK #65 (golden v12)-тай байт-ижил.
